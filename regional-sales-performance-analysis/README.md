# Regional Sales Performance Analysis

## Business Problem

A national SaaS company needs to understand whether revenue performance differs meaningfully across its five U.S. sales regions and identify which factors — product mix, discounting behavior, deal cycle length — most strongly drive revenue outcomes. These insights will inform FY2026 territory planning, quota-setting, and sales enablement priorities.

## Approach

This project performs a rigorous statistical analysis on 24 months of regional sales data (4,320 records across 5 regions, 3 product lines, and 60 sales reps):

1. **Exploratory Data Analysis** — Revenue distributions, trends, and product mix breakdowns by region
2. **Hypothesis Testing** — One-way ANOVA to test whether mean revenue differs across regions, followed by pairwise Welch's t-tests with Bonferroni correction
3. **Correlation Analysis** — Identifying relationships between revenue, discounting, customer satisfaction, and deal cycle length
4. **Seasonal Decomposition** — Quantifying monthly and quarterly patterns to support quota adjustments
5. **Rep Performance Profiling** — Identifying top/bottom performers and coaching opportunities

## Key Findings

- Regional revenue differences are **statistically significant** (ANOVA p < 0.001), with West and Northeast leading
- **Discounting does not meaningfully increase revenue** but is negatively correlated with customer satisfaction
- Clear **seasonal pattern**: Q4 revenues are 15-20% above average; Q1 sees comparable troughs
- Southwest has the **fastest growth trajectory** despite lower absolute revenue — a territory worth investing in

## How to Run

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. (Optional) Regenerate synthetic data
cd data && python generate_data.py && cd ..

# 3. Open and run the analysis notebook
jupyter notebook analysis.ipynb
```

All cells are designed to run sequentially. Figures are saved to the `figures/` directory automatically.
